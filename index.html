How it works

像晾衣服一样，把东西晾起来

不用切窗口、不用翻文件夹。截了图想等会儿再发，复制了一段话怕弄丢，先晾着。

1

截图或复制

Win+Shift+S、⌘⇧4 截的图，复制的文件、文字、链接，都会自己挂上绳。

2

鼠标推到屏幕顶上

绳子平时藏起来不挡事，鼠标一碰屏幕最上沿，它就垂下来。

3

单击复制；往下拖进微信、文件夹；双击钉到屏幕上当参考图。

Help

安装帮助

Windows 弹出「Windows 已保护你的电脑」怎么办？

因为晾晾是个刚发布的小软件，还没有买微软的代码签名证书，所以 Windows 会先拦一下。点「更多信息」，再点「仍要运行」就能装。杀毒软件拦的话，选「允许」或「信任此程序」。

Mac 提示「无法验证开发者」或「已损坏」怎么办？
  1. 先把 Pegline.app 拖进「应用程序」文件夹。
  2. 在它上面右键（或按住 Control 点一下）→「打开」→ 再点「打开」。
  3. 还不行：打开「系统设置 → 隐私与安全性」，往下拉，点「仍要打开」。
  4. 还提示已损坏：打开「终端」，粘贴 xattr -dr com.apple.quarantine /Applications/Pegline.app 回车。
Mac 下哪个版本？

点屏幕左上角苹果图标 →「关于本机」。写着「芯片 Apple M1/M2/M3/M4」就下 Apple 芯片版；写着「处理器 Intel」就下 Intel 版。

快捷键有哪些？

Windows：Ctrl+Alt+S 截图，Ctrl+Alt+V 把剪贴板挂上去，Ctrl+Alt+T 放下 / 收起绳子。
Mac：⌃⌥S、⌃⌥V、⌃⌥T，⌘⇧4 截的图也会自己挂上来。

它会不会偷看我的剪贴板？

晾晾只在你自己的电脑上读剪贴板，用来把新截图、新复制的东西挂上绳，不联网、不上传。你也可以在设置里改成「只收截图」或「只靠拖拽」。详见隐私说明。

怎么卸载？

Windows：设置 → 应用 → 已安装的应用 → 晾晾 Pegline → 卸载。Mac：把 Pegline.app 拖进废纸篓。
