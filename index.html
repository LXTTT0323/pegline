七套皮肤

同一根绳子，七种性格

每套皮肤的绳子、夹子、卡片都不一样，绳上还有会动的小东西：走钢丝的小人、巡逻的小机甲、被你吓飞的麻雀。

    隐私
    不联网。不注册。不上传。

    你晾上去的东西只存在自己电脑的一个文件夹里，晾晾也不会去读别的地方。它只在本机看剪贴板，好把新截图挂上绳；不想让它看，就在设置里改成「只靠拖拽」。完整的隐私说明 →

    为什么做它

    我每天要截很多图：报错、设计稿、聊天记录、验证码。截完往往马上就要用，用完又找不到，桌面上永远躺着几十张「截屏」。

    所以我在屏幕顶上拉了一根绳子，像在阳台上晾衣服一样，把这些东西先晾着。要用的时候一伸手就拿到，不要的就让它自己消失。

    晾衣绳这个点子最早来自 Alejandro Buján 的开源 macOS 应用 Tendedero。晾晾是受它启发、从头写的 Windows 和 Mac 版本，又加上了 PDF 翻页、虚影模式、左右两边挂绳和七套皮肤。

    安装帮助
    Windows 弹出「Windows 已保护你的电脑」

    晾晾还没有买微软的代码签名证书，所以 Windows 会先拦一下。点「更多信息」→「仍要运行」就能装。杀毒软件拦的话，选「允许」或「信任此程序」。

    Mac 提示「无法验证开发者」或「已损坏」
    1. 把 Pegline.app 拖进「应用程序」。
    2. 在它上面右键 →「打开」→ 再点「打开」。
    3. 还不行：「系统设置 → 隐私与安全性」往下拉，点「仍要打开」。
    4. 提示已损坏：打开「终端」，粘贴 xattr -dr com.apple.quarantine /Applications/Pegline.app 回车。
    Mac 下哪个版本？

    左上角苹果图标 →「关于本机」。写着「芯片 Apple M1/M2/M3/M4」下 Apple 芯片版；写着「处理器 Intel」下 Intel 版。

    它会不会偷看我的剪贴板？

    只在本机读，用来把新截图、新复制的东西挂上绳，不联网、不上传。也可以在设置里改成「只收截图」或「只靠拖拽」。

    以前装过 Pinly 怎么办？

    晾晾就是 Pinly 改名后的新版本。装上晾晾第一次打开，会自动把 Pinly 绳上的东西搬过来，之后在「设置 → 应用」里卸载 Pinly 就行。

    怎么卸载？

    Windows：设置 → 应用 → 已安装的应用 → 晾晾 Pegline → 卸载。Mac：把 Pegline.app 拖进废纸篓。
